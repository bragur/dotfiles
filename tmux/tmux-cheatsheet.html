tmux

personal cheat sheet
prefix = C-a
Sessions
prefix oSessionX — fuzzy session picker
prefix TSesh — fzf full picker (all / tmux / configs / zoxide / find / kill)
prefix KSesh — compact gum picker
prefix jPopup scratch terminal
prefix dDetach from session
prefix $Rename current session
prefix sList sessions (tree view)
Sesh fzf bindings: ctrl-a all · ctrl-t tmux · ctrl-g configs · ctrl-x zoxide · ctrl-f find · ctrl-d kill
Windows
prefix cNew window
prefix +Jump to last window
prefix ,Rename current pane title
prefix 1 – 9Switch to window N (1-indexed)
prefix n / pNext / previous window
prefix &Kill window
Panes
prefix sSplit — side by side (horizontal)
prefix hSplit — stacked (vertical)
prefix xKill pane (no confirmation)
prefix bBreak pane into new window
prefix mMerge pane from another window
prefix qShow pane numbers (3 s)
prefix zZoom / unzoom pane
Pane Navigation no prefix nvim-aware
C-h / C-lMove left / right
C-j / C-kMove down / up
C-\Last pane
C-_Jump to pane 1 & toggle zoom
Smart Splits: these pass through to Neovim when focused on a Neovim pane — no extra binding needed.
Pane Resize no prefix
M-← / M-→Resize left / right by 2
M-↑ / M-↓Resize up / down by 1
M-S-← / M-S-→Resize left / right by 20
M-S-↑ / M-S-↓Resize up / down by 10
Layouts
prefix LToggle even-horizontal / even-vertical
prefix C-vEven-vertical layout
prefix SpaceCycle through preset layouts
Copy Mode vi keys
prefix vEnter copy mode
vBegin selection
yCopy selection to clipboard (pbcopy)
C-h/j/k/lNavigate panes from copy mode
/Search forward
?Search backward
q / EscExit copy mode
Config & Misc

prefix aSend prefix to nested tmux session
prefix C-aSend literal C-a to shell
prefix :Open command prompt
prefix ?List all key bindings
prefix tShow clock
